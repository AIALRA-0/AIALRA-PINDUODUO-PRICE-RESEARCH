# 多轮采集规则

## 为什么必须多轮

拼多多搜索结果会受到查询词、排序、地区、登录状态和时间影响

一轮结果只能表示一个页面切片

至少三轮能够发现不同写法、排名变化和重复出现的稳定商品

## 固定上限

- 查询词数量为三至五个
- 每轮最多读取一个页面
- 同时打开的页面数量为一个
- 相邻自动动作至少间隔三秒
- 风险事件后的自动重试次数为零
- 当前运行的观察缓存时间为十五分钟
- 详情核验数量最多为八个

## 饱和判定

每轮按照稳定商品 ID 统计第一次出现的商品

连续两轮新增数量不高于计划阈值后，结果可以标记为趋于饱和

达到轮次或时间上限但没有满足条件时，最终结果必须写明尚未饱和

## 证据等级

- A 级表示已经打开详情页并核验目标规格、在售状态和直接价格
- B 级表示只有搜索卡片或详情字段不完整
- C 级表示只有摘要、推断或无法复核的文字

最终赢家必须拥有 A 级证据
